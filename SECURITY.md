# Security reporting

This repository contains a standalone parser demonstration, not an audited
production security component. See docs/trust-boundary.md for its limits.

For a non-sensitive defect in this sample, a minimal synthetic reproduction may
be submitted through Issues. Never attach actual device identifiers, credentials,
customer information or private product source.

For sensitive reports, use GitHub's private vulnerability reporting interface
if the maintainer has enabled it under Security > Advisories. If it is unavailable,
ask the maintainer in a public issue to establish a private reporting channel,
without disclosing the vulnerability. No response-time commitment is currently made.
